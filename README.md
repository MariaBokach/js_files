# Демонстрация работы с текстовыми файлами в JavaScript
Учебный проект, показывающий различные способы чтения, записи работы с текстовыми файлами в браузере и в Node.js.

index.html - Разметка страницы: выбор файла, drag-and-drop, textarea, кнопки сохранения  
script.js - чтение и запись файлов в браузере 
script_node.js - Пример работы с файлами в Node.js
my_file.txt - Тестовый файл для проверки чтения 
style.css + rimma.TTF - Оформление интерфейса
